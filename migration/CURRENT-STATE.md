## Изменено поверх перемещений

Содержательных изменений production implementation не найдено. Изменены только:

- workspace manifests и `workspace:*` зависимости;
- TypeScript paths и относительные пути конфигурации;
- относительные импорты package-owned Storybook declarations;
- корневая композиция Storybook и сохранённые route baselines;
- package inventory, owner ledger и history-import evidence;
- проверки корневой структуры monorepo.

Эти изменения привязаны к промежуточным путям и должны быть пересчитаны после
окончательного физического размещения. Они не являются изменением поведения
пакетов.
