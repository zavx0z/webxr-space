# Правила Nodes

- Перед созданием или изменением структуры читать
  [единые правила предметов, src и shared](../PROJECT.md#модули-пакета).
  Это нормативный источник; собственную копию правил размещения здесь не поддерживать.
- Новые и изменяемые комментарии, TSDoc и документация пишутся на русском.
- Авторские DOM props/refs/events следуют [общему контракту](../PROJECT.md):
  глобальные браузерные типы и расширения платформы, без импорта типов реализации
  DOM и без `as unknown`/`as any` для их стыковки. Geometry helpers — публичный API,
  а `NodeRect`/`NodeShape` — доменные типы; они разрешены.
- TypeScript/JavaScript — без завершающих точек с запятой. JSX props и авторский
  CSS оформляются многострочно; `css` остаётся compile-time intrinsic.
- `@nodes/tree` владеет моделью и значениями. GraphView показывает граф и
  обслуживает навигацию; GraphEditor использует GraphView и добавляет управление
  изменениями. Просмотр не импортирует редактор и не создаёт вторую модель.
- Измерение CSS принадлежит платформе. Nodes не читает private Renderer state,
  не разбирает CSS и не создаёт дополнительный Document, Canvas или Renderer.
  Подтверждённый пробел публичного контракта фиксируется воспроизведением;
  изменение platform owner требует отдельного поручения.
