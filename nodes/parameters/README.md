# Параметры

Пакет `@nodes/parameters`. Описания категорий и компонентов находятся в их `index.ts`.
Реализации — в `src` компонентов, проверки — в `tests`, общая проекция Parameter Store — в `shared`.

Живые ноды используют те же готовые TextParameter, NumberParameter и остальные
компоненты, что и самостоятельная композиция. Общий `Parameter` из `shared`
подписывается на переданный Store, выбирает компонент и передаёт ему значения,
сокеты и callbacks. Он не создаёт Store и не дублирует разметку UI-полей.

Готовые компоненты сохраняют `labelHidden`, `spacingBefore`, состояния подключения
и точные ID сокетов. Один параметр может иметь несколько сокетов одной стороны;
повтор ID отклоняется. Размеры сложных параметров и интервалы согласованы
с числовой геометрией Nodes.

`OutputParameter` показывает значение только для чтения. Направление соединения
задаётся отдельно у Socket; имя компонента не обозначает выходной сокет.

[Проверки проекции](shared/tests/projection.test.ts) сопоставляют DOM и CSS всех
15 готовых компонентов с отображением из модели, проверяют адресованный ввод,
сохранение полей при обновлении и очистку подписок.
