# Сокеты

Пакет `@nodes/sockets`. Компонент Socket, его разметка и документация находятся в `socket/index.tsx`.
Проверки находятся в `socket/tests`, общие предустановки и метрики — в `shared`.

`resolveSocketKind` и `resolveSocketShape` из `@nodes/sockets/presets`
нормализуют строки модели для представления сокета. Неизвестный вид даёт
`custom`, неизвестная форма — `undefined`, чтобы Socket выбрал предустановку.
Эти правила общие для содержимого ноды и проекции параметров.
