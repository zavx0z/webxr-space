# WebXR

WebXR — единая визуальная платформа для приложений с пространственной сценой,
экранами и интерфейсом. Компоненты описывают содержимое через HTML-подобный TSX
и CSS; платформа связывает документ, раскладку, ввод и отрисовку WebGPU.

## Устройство платформы

Одно приложение использует один semantic Document, один Canvas, одно Space,
один ViewPoint и общий цикл ввода и кадров. Display и HUD показывают содержимое
того же документа. Обновления сохраняют существующие элементы и состояние
компонентов.

- **DOM** хранит дерево документа, атрибуты, события, фокус и состояние элементов.
- **Template и Component** обеспечивают компиляцию TSX/CSS и жизнь компонентов.
- **Renderer** вычисляет стили, раскладку и данные для рисования и выбора цели ввода.
- **Engine и WebGPU** обеспечивают объекты сцены и выполнение отрисовки.
- **Space и Browser** связывают пространственные элементы с приложением,
  Canvas, вводом и кадрами.
- **UI** предоставляет общие компоненты интерфейса.
- **NodeTree, Layout и Nodes** отвечают за модель графа, его раскладку и редактор.
- **DevTools** предоставляет диагностику существующего документа и его проекций.

Состав самостоятельных пакетов задан в `package.json#workspaces`.
Границы пакетов определяют ответственность; подробные контракты находятся
у соответствующих реализаций.
