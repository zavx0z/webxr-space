# TypeDoc

Пакет `@webxr/typedoc` (далее — TypeDoc) превращает экспортируемые TypeScript-типы
в читаемый справочник. Его собственный закон: сигнатуры и поля сохраняют
структуру типов, а авторские описания и примеры дополняют её текстом.

Работу начинает запрос на разбор исходного файла. Parser разрешает декларации
и их зависимости через компилятор, собирает эффективные поля, описания и примеры,
затем завершает сессию. Потребитель получает готовый справочник и снимки
прочитанных источников для проверки актуальности перед публикацией. Каждая
декларация содержит также JSON Schema, построенную тем же checker и дополненную
описаниями TSDoc. Рекурсия использует стандартный $ref; непредставимые JSON-типы
и не поддержанные формы закрываются схемой not с пояснением.
Ошибочный исходник завершает разбор ошибкой; документируемые модули остаются
данными и не исполняются.

Поддерживаются экспортируемые интерфейсы и псевдонимы типов, реэкспорты,
наследование, преобразованные объектные типы и кортежи. Скалярные типы
сохраняются сигнатурой; свойства объектов и элементы кортежей получают
отдельные строки. Читатель видит типы полей, обязательность, документированные
значения по умолчанию и примеры. Значения по умолчанию показываются как
авторский текст без вычисления.

Представление принимает готовую модель и обновляет разделы справочника,
сохраняя корень и элементы с прежними именами. Пустая модель получает явное
сообщение. Обычные описания переносятся по ширине, а длинные сигнатуры остаются
цельным кодом с локальной горизонтальной прокруткой. При чтении оглавление
следует за собственным содержимым видимого поля: вложенные поля не удерживают
выделение родителя, чей текст уже ушёл за границу области просмотра.

TypeDoc располагается в [общем Document приложения](../PROJECT.md#авторство-и-подключение-приложения),
где родитель задаёт область просмотра. Пакет `@webxr/markdown` (далее — Markdown)
отвечает за [оформление описаний и примеров](../markdown/README.md),
а [CodeEditor](../ui/views/code-editor.md) — за подсветку и просмотр кода.
TypeDoc владеет разбором и структурой справочника; выбор исходников,
проверка их актуальности и публикация принадлежат вызывающему инструменту.
