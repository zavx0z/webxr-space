# Архитектурные решения visual monorepo

Этот каталог хранит принятые решения, на которых основана миграция. Он
отделяет решения владельца от исторических предложений, промежуточной
реализации и доказательств приёмки.

Статусы:

- `принято` — обязательное основание дальнейшей работы;
- `предложено` — требует решения владельца;
- `заменено` — историческое решение, которое больше не действует;
- `отклонено` — рассмотренный, но запрещённый путь.

Исполняемый порядок находится в
[`migration/PLAN.md`](../../migration/PLAN.md). Каждый его шаг обязан ссылаться
на решение из этого каталога. Оперативные таблицы в `architecture/*.json` и
`migration/*.json` являются проекциями решений, а не самостоятельным источником
архитектурной истины.
