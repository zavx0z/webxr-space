# Space

`<space>` — базовый корень пространственной сцены одного semantic Document.
Класс `SpaceElement` экспортируется из `@zavx0z/dom/space`.
Элемент создаётся без регистрации фабрик и не создаёт Canvas, Renderer или цикл кадров.

## Текущий API

- `frameloop`: `demand` по умолчанию, `always` для непрерывного общего цикла кадров.
- `background`: цвет фона сцены, по умолчанию `#000000`.
- Обычные методы DOM управляют детьми; их идентичность и документ сохраняются.

Space принимает один `<viewpoint>`, дисплеи, пространственные объекты и не более
одного HUD. Отсутствие камеры допустимо при построении дерева; подключение
Browser требует одну камеру. Ресурсы Geometry и Material принадлежат объектам,
обычный HTML — Display или HUD.

`SpatialElement` — базовый тип для пространственных расширений. Его доступный
только для чтения `spaceChildKind` определяет допустимость включения в сцену.

```tsx
<space frameloop="demand" background="#101820">
  <viewpoint x={0} y={-600} z={900} targetZ={900} />
</space>
```

Тесты находятся в `tests`; зависимости тестов импортируются относительными
путями. Запуск: `bun test dom/space/tests`. Названия и сообщения `expect` — на русском.
