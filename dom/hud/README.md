# HUD

`<hud>` — базовый корень интерфейса, следующего за камерой общего Space.
Класс `HUDElement` экспортируется из `@zavx0z/dom/hud` и создаётся Document
без регистрации фабрик. В одном Space допускается не более одного HUD.

## Текущий API

Сохраняется действующий API: `distance` задаёт расстояние до плоскости HUD
в миллиметрах, по умолчанию `1000`. Для проекции требуется положительное
расстояние. Необязательный `id` используется для поиска и селекторов;
владельцем проекции остаётся сам элемент.

HUD содержит обычные интерфейсные элементы. Их CSS, события, фокус и состояние
принадлежат тому же Document. Перенос между Display и HUD сохраняет идентичность
узлов. Canvas, Renderer, камера и жизненный цикл остаются общими для приложения.

```tsx
<space>
  <viewpoint />
  <hud distance={600}>
    <button>Команда</button>
  </hud>
</space>
```

Тесты и их TypeScript-конфигурация находятся в `tests`.
Запуск: `bun test dom/hud/tests`. Названия и сообщения каждого `expect` — на русском.
Импорты из других пакетов в тестах относительные, без дополнительных зависимостей DOM.
