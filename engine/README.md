# Движок

`@zavx0z/engine` предоставляет пространственную основу WebXR: объекты сцены,
геометрию, материалы, математику, анимацию, загрузку моделей и данные шрифтов.
Эти структуры используются для представления сцены и содержимого документа.

## Ответственность

- Преобразования и иерархия объектов, камеры ViewPoint и пространственные расчёты.
- Геометрия, meshes, линии, текст, материалы и источники света.
- Raycast, загрузка glTF и анимация.
- Данные шрифтов и геометрия текста.

Engine не выполняет WebGPU-рисование. WebGPU владеет конкретными GPU-ресурсами
и командами, Browser — Canvas, вводом и циклом кадров. В приложении объекты
Engine являются представлением содержимого общего Document.

Система координат правая: X вправо, Y вперёд, Z вверх. Единица расстояния —
миллиметр. Углы низкоуровневого Engine API задаются в радианах; авторский
контракт пространственных компонентов описан отдельно в пакете Space.

## Публичный API

Основной вход — `@zavx0z/engine`: `Object3D`, `ViewPoint`, геометрии, материалы,
объекты сцены и математические типы. `@zavx0z/engine/default-font` предоставляет
вход для стандартного шрифта, а `@zavx0z/engine/fonts/...` — опубликованные
файлы Inter и JetBrains Mono. Точный состав определяется `package.json#exports`.

## Документация и проверки

Общий контракт изложен в TSDoc `src/index.ts`, детали — рядом с реализациями.
Проверки основного API, мировых матриц и системы координат находятся в `tests`.
Команда `bun run check` из директории пакета проверяет типы и выполняет тесты.

Storybook обнаруживает пакет по структуре рабочего пространства и показывает
этот README. Пустой манифест, повторяющий метаданные пакета, не требуется.
