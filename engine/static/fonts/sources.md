# Font sources

Inter Bold, Italic and Bold Italic are unmodified static TTF files from
[Inter 4.1](https://github.com/rsms/inter/releases/tag/v4.1),
`Inter-4.1.zip/extras/ttf`. License: `inter-4.1-ofl.txt`.

JetBrains Mono Regular, Italic and Bold Italic are unmodified TTF files from
[JetBrains Mono](https://github.com/JetBrains/JetBrainsMono/tree/master/fonts/ttf).
Their source Git blob IDs are respectively
`711830ede02a366f8b99f88e52f3148405e67eaf`,
`71429b0108163b389f5db2ed0a9d17038966db88`, and
`6ff8032a5f1fafa87c455b0aa0d56d2406c61bc8`.
License: `jetbrains-mono-ofl.txt`.

The existing Inter Regular and JetBrains Mono Bold assets are retained.
