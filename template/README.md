# Шаблоны TSX

`@zavx0z/template` связывает авторское описание интерфейса с готовыми операциями
над DOM и стилями. Пакет предоставляет компилятор TSX/CSS, HTML-шаблоны
и отдельный разбор деклараций для потребителей DSL.

## Публичные контракты

- **Компиляция TSX/CSS.** Входы `@zavx0z/template/compiler` и
  `@zavx0z/template/bun` преобразуют авторские шаблоны в формат скомпилированных
  компонентов. Контракт результата опубликован в `@zavx0z/template/compiled`.
- **HTML-шаблоны.** Основной export предоставляет `html` и `compile` для создания
  DOM-содержимого и обновления существующих узлов.
- **Разбор деклараций.** `parse` читает текст переданного callback и извлекает
  HTML-подобную структуру, не вызывая сам callback.
- **JSX runtime.** `@zavx0z/template/jsx-runtime` и `jsx-dev-runtime` задают
  точки входа для авторского JSX и его типов.

В governed TSX авторский CSS записывается внутри ``style={css`…`}``;
компилятор обрабатывает этот intrinsic. Это не регистрация глобальной темы:
общие stylesheet принадлежат пакетам и подключаются приложением.

## Границы ответственности

Template определяет формат шаблона и его привязки. Component управляет
состоянием и эффектами компонентов, DOM хранит элементы, Renderer вычисляет
стили и раскладку, а Browser и WebGPU обеспечивают приложение и отрисовку.
Пакет Template не создаёт Canvas, камеру или параллельное дерево приложения.

## Документация и проверки

Назначение основных API описано в TSDoc `index.ts` и публичных точек входа.
[Контракт фрагментов](fragments.md) раскрывает композицию и сохранение узлов.
Проверки компилятора, фрагментов, привязки document и props находятся в `tests`.
Команда `bun run check` из директории пакета проверяет типы и выполняет тесты.

Состав рабочего пространства задаёт `package.json#workspaces`; описание
пакета остаётся в README и TSDoc владельца.
