# Markdown

Пакет `@webxr/markdown` (далее — Markdown) превращает текстовый документ в
семантическое содержимое приложения. Его собственный закон: показ документа
и поиск его ресурсов используют один разбор и одинаковые правила допустимого
содержимого. Благодаря этому ссылки и изображения, обнаруженные для загрузки,
соответствуют тому, что читатель увидит в документе. [Parser](parser/index.ts)
принимает текст и базу адресов, возвращая модель блоков. Самостоятельный
[сбор адресов](destinations/index.ts) обходит эту модель для вызывающего инструмента.
Обе операции публикуют собственные входные и выходные контракты.

Работу начинает переданный текст. Markdown разбирает его, составляет заголовки,
абзацы, списки, таблицы и код, затем обновляет содержимое при изменении исходника
или базы относительных адресов. Корневой элемент документа сохраняется;
переключение переноса текста меняет представление той же области. Вызывающая
композиция задаёт размеры и оформление, а читатель получает связный документ
с вложенными ссылками, изображениями и блоками кода.

Markdown поддерживает CommonMark: заголовки, абзацы, вложенные списки и цитаты,
разделители, выделение, ссылки, изображения и код. Таблицы сохраняют заголовки,
порядок строк, выравнивание и строчное оформление ячеек. Разрешённое подмножество
HTML позволяет группировать и оформлять содержимое; неизвестная разметка
показывается текстом, а допустимость адресов определяет общий parser.

## Mermaid

Блок Mermaid начинает асинхронный разбор flowchart. Markdown передаёт
нормализованный граф общему просмотру нод: диаграмма появляется после измерения
её элементов и готовности раскладки. При обновлении текста сохраняется
идентичность уцелевших нод, а ошибка разбора выводится рядом с исходным кодом.

Поддерживаются горизонтальные и вертикальные направления, прямоугольники,
круги, овалы, обычные связи без подписей и стрелки на одном или обоих концах.
За рамками этого набора parser сообщает о неподдержанном случае. Измерение,
сохранение элементов и подготовку сцены определяет
[цикл показа графа](../nodes/measurement-gap.md).

Markdown участвует в [едином Document приложения](../PROJECT.md#авторство-и-подключение-приложения).
Общее выделение связывает его текст, код и соседнее содержимое; ввод и clipboard
принадлежат приложению. Блоки кода используют
[редактор только для чтения](../ui/views/code-editor.md), а загрузка изображений
и их анимация следуют [общему жизненному циклу ресурсов](../renderer/html/font-images.md).
Ответственность Markdown заканчивается на семантической композиции документа;
размеры, переносы и рисование обслуживает платформа.
