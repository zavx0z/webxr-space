# CodeEditor: размер области и прокрутка

CodeEditor использует обычный semantic `<section>` с `overflow: auto`.
Метрики, полосы и ввод прокрутки принадлежат общему Renderer; собственный
scrollbar/controller в компоненте отсутствует.

По умолчанию сохраняется viewport 520 × 220 px. Через `style` можно задать
другую высоту, в том числе `height: auto`. Автоматическая высота определяется
реальными строками и отступами; внутренние `ul`, `pre` и `code` не требуют
`height: 100%`. В фиксированной области колонки растягиваются по её высоте.
Колонка номеров не сжимается (`flex-shrink: 0`), а код занимает остаток ширины.

Markdown использует `height: auto`. Для трёх строк это 48 px текста плюс
16 px вертикальных отступов и границы, без пустого viewport высотой 160 px.

## Регрессионный случай Renderer

Исправление `61fcf99` нормализует только машинную погрешность scroll extent.
В прежней раскладке CodeEditor причина была другой: распределение отрицательного
свободного пространства между flex items, ограниченными явным `min-width`.

Минимальное воспроизведение: `CodeEditorFlexMinimumFixture` из
`ui/views/code-editor.fixture.tsx`. Для родителя 520 px ожидаются дочерние ширины
42 и 478 px, `maxScrollLeft = 0`. До исправления второй элемент получал
478.0203437104936 px, а `maxScrollLeft` составлял около 0.02034 px.

Владелец — `@zavx0z/renderer`, `renderer/src/renderer.ts`,
`distributeFlexSpace`. Теперь элементы, достигшие явного или автоматического
минимума, исключаются из дальнейшего сжатия. Для остальных размеры заново
рассчитываются от исходных внутренних flex bases с учётом `flex-shrink`.
Воспроизведение получает ровно 42 и 478 px без горизонтальной прокрутки.

Общие проверки находятся в `renderer/tests/flex-shrink.test.ts`: обе оси,
последовательное достижение минимумов, различные веса, процентные ограничения,
box sizing, отступы, дробные размеры и неизбежное переполнение. Правило взвешивания
и фиксации ограниченных элементов следует
[CSS Flexbox §9.7](https://www.w3.org/TR/css-flexbox-1/#resolve-flexible-lengths).
Capability ID пока не назначен.
