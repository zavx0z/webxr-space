# Модель редактирования кода

`@zavx0z/ui/code-editor-model` владеет текстовыми транзакциями редактора.
Она не создаёт DOM, listeners, clipboard, раскладку или GPU-ресурсы.
CodeEditor и Interpreter используют одну и ту же модель; стандартный
`Document.Selection` не расширяется до несовместимого multicursor API.

## Состояние и выделения

`createCodeEditorModel({value, readOnly?, selections?, primary?, historyLimit?})`
возвращает `CodeEditorModel`. `snapshot` и содержащиеся в нём диапазоны заморожены.
`subscribe` сообщает только последующие изменения, возвращает функцию отписки.
`revision` монотонно увеличивается только при изменении текста, включая preview IME,
undo, redo и отмену composition. Изменение выделения сообщает новый snapshot,
но не повышает текстовую revision и не требует повторной токенизации или TSX render.

Диапазон `{anchor, head}` использует смещения UTF-16 в исходном `value`.
Направление сохраняется. `primary` — индекс основного диапазона в отсортированном
по исходнику массиве. Пересекающиеся диапазоны и совпадающие каретки объединяются;
каретка на границе диапазона объединяется с ним. Соседние непустые диапазоны не
объединяются. Направление основного диапазона сохраняется при слиянии.
Пустой набор сбрасывается в одну каретку на позиции 0. Целочисленные смещения
ограничиваются длиной текста, нецелые и нечисловые значения отвергаются атомарно.

`setSelections` заменяет набор, `addSelection` добавляет новый основной диапазон.
`selectedText()` собирает только непустые диапазоны в порядке исходника через `\n`.
Параметр позволяет задать другой разделитель. Номера строк не являются частью value.

## Редактирование

- `insertText` заменяет все выделения и вставляет у всех кареток одним шагом.
  `insertText("")` удаляет только непустые выделения — это операция удаления для cut.
- `deleteBackward` / `deleteForward` удаляют выделение или соседнюю единицу текста
  у каждой каретки. Перекрывающиеся расширенные диапазоны объединяются до изменения.
- `paste` распределяет строки в порядке исходника, когда число строк равно числу
  диапазонов. Иначе весь исходный payload вставляется в каждый диапазон. Массив
  строк задаёт явные части; при несовпадении количества они объединяются через `\n`.
- Все позиции вычисляются относительно одного исходного состояния, поэтому ранние
  вставки не сдвигают адреса последующих. Итоговые каретки учитывают все изменения.
- `undo` / `redo` восстанавливают и текст, и направления, и основной диапазон.
  Изменения выделения сами по себе не добавляются в историю. По умолчанию остаётся
  100 транзакций; `historyLimit: 0` отключает историю.
- `readOnly` запрещает текстовые команды и undo/redo, но не выделение и копирование.

`move(backward|forward, {unit, extend})` поддерживает grapheme, word, line и document.
`line` означает начало/конец логической строки, не вертикальную навигацию.
Слова определяются `Intl.Segmenter`, знаки препинания и пробелы пропускаются до
следующего слова. Unicode grapheme segmentation не разрывает surrogate pairs,
combining marks, ZWJ emoji и CRLF. Индексы сегментов вычисляются лениво для
затронутой логической строки и сохраняются в ограниченном кэше; один шаг движения
не сегментирует весь многострочный документ. `moveVertical(up|down, {extend})`
работает по логическим строкам без wrap и сохраняет желаемую UTF-16 колонку
при прохождении через короткие строки. Вертикальная навигация с визуальными
переносами принадлежит геометрии Renderer, не этой модели.

## IME и внешнее значение

`beginComposition` сохраняет исходное состояние. Каждый `updateComposition(text)`
заменяет исходные выделения, а не дописывает к предыдущему preview. Все каретки
получают одинаковый текущий composing text. `commitComposition(finalText?)`
записывает один шаг undo; `cancelComposition` полностью возвращает исходное
состояние и не уничтожает redo. Обычные изменения и смена выделения во время
composition запрещены. Undo во время composition отменяет только preview.
Переход в readOnly также отменяет preview. Неверное значение update/commit
отвергается без частичного изменения состояния.

`replaceValue(value, {selection: "reset" | "map"})` — явная внешняя синхронизация,
не шаг undo. Она отменяет composition и очищает старую историю. `reset` ставит
каретку в начало; `map` вычисляет минимальную замену через общий префикс/суффикс
и переносит диапазоны с правой привязкой границ. Это не diff произвольного списка
независимых изменений. Повтор текущего значения является no-op, в том числе
когда controlled consumer возвращает текущий preview IME через props.

## Проверки

`bun test ui/tests/editor-transactions.test.ts` покрывает нормализацию, mapping,
multi-paste, Unicode, readOnly, замороженные snapshots, cleanup подписок,
ограничение истории, IME commit/cancel и ошибки во время composition.
