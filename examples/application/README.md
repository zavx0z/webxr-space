# Приложение WebXR

Запуск из корня монорепозитория:

```sh
bun run application:dev
```

Сборка для обычного статического HTTP-сервера:

```sh
bun run application:build
```

Dev и production используют один `buildApplication` и один Template compiler.
Dev-команда запускает локальный сервер и печатает его адрес. После изменения
исходников запустите её повторно. Для этого примера отдельного HMR нет.

`main.tsx` подключает `App` единственным `attach({canvas, app: <App />})`.
Сборка отдельно компилирует публичную тему UI в `theme.css`; Browser загружает
её по умолчанию через link. HTML владеет native Canvas и объявлением default font. App владеет semantic
Space, ViewPoint, Display, HUD и содержимым. Они объявлены публичными TSX-компонентами
пакета `@zavx0z/space`. Фиксированным соседям не нужны авторские keys;
в динамических списках key сохраняет identity элемента при перестановке.

Сцена использует только правую систему Z-up и миллиметры: камера расположена
на Y = −800 мм, Display повёрнут в плоскость XZ, его верх направлен по +Z.
CSS-размеры остаются в пикселях; `worldUnitsPerPixel` задаёт мм на CSS px.

Нажмите счётчик, прокрутите его область и перенесите карточку между Display и
HUD. Перенос сохраняет тот же Element, обработчики и состояние компонента.
Пустая область HUD пропускает мышь к Display и сцене. Панель перекрывает
нижнее содержимое. Свободное место сцены принимает жесты камеры.

`attach` завершается после первого представленного кадра. Ошибка освобождает
App и созданные ресурсы; `dispose()` освобождает компоненты, ввод, кадры и
Canvas claim. Повторный запуск на том же Canvas допускается после dispose.

Известное отдельное воспроизведение: BoxGeometry в Engine строит боковые грани
в неверных плоскостях. Mesh размером 100×100×100 мм справа от Display должен
быть кубом, но с фронтальной Z-up камерой видны полосы. Источник:
`engine/src/geometries/box-geometry.ts`, функция `buildPlane`. Это оставлено
видимым в эталоне; готовность browser-host не является приёмкой геометрии.

При ручной проверке щелчок по Button увеличивает счётчик, а Enter после
фокусировки кнопки — нет. Стандартная keyboard-activation кнопки остаётся
отдельным вопросом DOM/Browser; пример не добавляет собственный обработчик
Enter, подменяющий это поведение платформы.
