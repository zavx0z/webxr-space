# Пространственные компоненты

`@zavx0z/space` (далее — Space) владеет авторским описанием объектов и проекций
в [едином Experience](../PROJECT.md#главный-закон). Все его компоненты используют
один пространственный контракт: правая система координат, X вправо, Y вперёд,
Z вверх, длины в миллиметрах.

## Трансформации

Положение задаётся одним `position={{x, y, z}}`, масштаб — одним
`scale={{x, y, z}}`. Масштаб безразмерный, по умолчанию единичный. Отрицательный
масштаб отражает объект; нулевые оси недопустимы. Положение объекта по умолчанию
нулевое. Вложенный объект задаёт трансформацию относительно своего родителя.

`rotation={{x, y, z}}` задаёт углы Эйлера в градусах с порядком XYZ, как
Blender XYZ Euler: сначала X, затем Y, затем Z относительно исходных осей.
Вместо углов программа может передать `quaternion={{x, y, z, w}}`.
Это взаимно исключающие формы одной ориентации; кватернион нормализуется.
По умолчанию ориентация единичная. Каждый вектор задаётся целиком и содержит
только конечные числа.

Эти имена и единицы обязательны для каждого компонента, который поддерживает
соответствующее пространственное свойство, включая новые компоненты.
ViewPoint и направленный Light принимают цель одним `target={{x, y, z}}`
в миллиметрах. Камера ориентируется на цель с фиксированной осью вверх Z;
она не получает отдельную конкурирующую ориентацию или геометрический масштаб.
Её `fov` сохраняет свой оптический контракт в радианах, `near` и `far` — в мм.
HUD следует камере, а Geometry и Material описывают ресурсы своих объектов.

Повторный render с теми же числовыми значениями сохраняет изменения от жестов
и команд через ref, даже если автор создал новые объекты props. Изменение
значений обновляет тот же semantic Element и сохраняет его identity и детей.
Удаление ранее заданного свойства возвращает его значение по умолчанию.

## Физический Display

Display описывает плоский дисплей через активный физический размер
`size={{width, height}}` в мм и разрешение матрицы
`resolution={{width, height}}` в пикселях. Оба значения обязательны.
Размеры положительные и конечные, разрешение состоит из положительных целых чисел.
Диагональ и плотность пикселей выводятся из этих характеристик.

`pixelRatio` определяет количество пикселей матрицы на один CSS px, по
умолчанию 1. CSS-область содержимого равна разрешению, делённому на pixelRatio.
Плотность по каждой оси определяется соответствующим физическим размером и
разрешением: разные пропорции описывают прямоугольные пиксели. Изменение
pixelRatio меняет масштаб интерфейса, сохраняя физический размер дисплея.
Оно не меняет плотность native Canvas, принадлежащую Browser Root.

`position`, `rotation` либо `quaternion` и `scale` следуют общему закону
трансформаций. Size описывает немасштабированную поверхность; scale меняет её
размер в сцене, сохраняя разрешение и CSS-раскладку. Центр Display является
началом его локальной системы; при нулевом вращении поверхность лежит в XY.

Изменение окна, камеры или расстояния обзора само по себе не меняет физических
характеристик дисплея. Приложение выбирает их явно; режим приближения изменяет
камеру. Display вычисляет проекционные величины для Browser внутри Space.
Его содержимое принадлежит тому же Document и использует общий ввод и кадр.
